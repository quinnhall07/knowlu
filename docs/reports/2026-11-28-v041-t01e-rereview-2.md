  - **The check.** `subscription_read.ts:64-69` now also throws `SubscriptionReadError(200)` when the body's
    `object` is not exactly `"subscription"`. This sits after the 404 and non-2xx branches, so it applies only to a
    2xx. A throw takes the handler's existing `catch` (`handler.ts:303-310`), which answers 502 before any write,
    mail or record.
  - **The tests.** `a_2xx_empty_object_is_a_failed_read` and `a_2xx_object_of_another_kind_is_a_failed_read` cover
    `{}`, `"invoice"`, `"checkout.session"`, `"list"` and `"Subscription"`. The last one pins case sensitivity.
  - **Reverted, they fail.** Without the `object` clause, every one of these bodies resolves, and `assertRejects`
    fails.
  - **The existing 2xx test.** Its fake body gains `object: "subscription"`, which is needed and matches what
    Stripe sends (the controller's fact).
  - **The words.** The `fetchSubscription` doc (`handler.ts:56-62`), the module doc (`subscription_read.ts:4-5`)
    and D6b (design note `:291-297`) now say "a 2xx body whose `object` is not `subscription`", which is what the
    code checks.
- **B. A 404 is logged: fixed.**
  - **The log.** `handler.ts:313-317` writes one `console.error` line, `stripe-webhook: ${type}: Stripe has no such
    subscription`, when a string id was read and the answer is `null`. Only `fetchSubscription`'s 404 gives that
    answer. The line holds the function name and the event type only, with no id, account id or body.
  - **The answer.** The next line is still `200 { ignored: "no subscription on <type>" }`, with nothing written,
    mailed or recorded.
  - **The test.** `a_404_on_the_subscription_read_is_ignored_as_before` (`handler_test.ts:1450-1467`) asserts that
    the logged lines equal exactly `[that text]` for both events. That pins the text, and also that only one line is
    written. It also asserts the line carries no `acc-1`, `sub_`, `cus_`, `cs_`, `evt_` or `@`, while keeping the
    status, body, `written` and `recorded` checks. Reverted, the log array is empty and the test fails.
  - **The design note.** D6b gains the clause that a 404 is logged by event type only, with its reason.
