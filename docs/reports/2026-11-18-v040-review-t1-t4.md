- **Where:** `site/index.html:14`, `site/joined.html:14`, `site/css/base.css:4`.

  - Make a Latin subset as WOFF2 (about 20 to 40 KB), with its primary name changed (name IDs 1, 4, 6, 16 and 17) to a name that contains neither "PT Serif" nor "ParaType", for example "Knowlu Display".

  - OFL condition 3 allows this: it reserves the name only "as presented to the users".
  - The other route is ParaType's written permission.

## Rulings asked for

- **Reserved Font Names, from the committed OFL headers:**

  | Family | Reserved Font Name |
  |---|---|
  | PT Serif Caption | "PT Sans", "PT Serif" and "ParaType" (`OFL-ptserifcaption.txt:2`) |
  | OpenDyslexic | OpenDyslexic (`OFL-opendyslexic.txt:2`) |
  | Albert Sans | none (`OFL-albertsans.txt:1`, a copyright line only) |
  | Zilla Slab | none (`OFL-zillaslab.txt:1`, "Copyright 2017, The Mozilla Foundation" only) |

- **Albert Sans and Zilla Slab as CSS2 latin subsets: allowed.**
  - A subset is a Modified Version: the OFL's definition covers "deleting … any of the components".
  - Only condition 3 restricts the name, and neither licence reserves one.
  - The other conditions are met: the OFL ships beside each family, and the family is distributed under it.
  - This rests on the google/fonts `OFL.txt` text. The OFL hash re-fetch in item 2 above confirms it.
- **A WOFF2 of PT Serif Caption: not allowed under that name.**
  - OFL 1.1 defines a Modified Version as including one made "by changing formats". WOFF2 also re-encodes the `glyf`/`loca` tables, so the result is not byte-recoverable.
  - Such a file cannot keep a primary name containing "PT Serif" without ParaType's written permission.
  - It is allowed under a new primary name, as M1 describes.
  - The same reasoning is why OpenDyslexic correctly ships upstream's own `.woff`.
