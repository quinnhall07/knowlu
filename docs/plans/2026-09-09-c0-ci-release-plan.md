**Goal:** A tag `v*` pushed to `quinnhall07/knowlu` produces, on GitHub's runners and with no laptop involved, a Trusted-Signing-signed NSIS installer, a Tauri updater signature made with a key that exists **only** as a CI secret, and a `latest.json` — published to Cloudflare Pages under `knowlu.com/releases/` and attached to a GitHub Release — and an installed Knowlu offers the next one as an in-app update.

**Architecture:** Two workflows. `ci.yml` runs the whole test gate on every push and pull request (`cargo test --workspace` at 0 warnings, the eol contract, a size gate on the engine). `release.yml` runs on a tag: it calls the same `scripts/release.ps1` the laptop used to run — now taught to take the updater key from the environment and the Trusted Signing profile from a path CI writes — then deploys `site/` with Wrangler and creates the GitHub Release. The updater keypair is regenerated once, its private half never touches a disk outside the runner, and the old key (which sat in OneDrive) is retired by the `pubkey` change. `release.ps1` stays runnable locally only as a **dry run** that bundles without updater artefacts, so a laptop can never again produce a shippable build.

**Tech Stack:** GitHub Actions on `windows-latest`; `dtolnay/rust-toolchain`; `Swatinem/rust-cache`; `tauri-cli` 2.x installed with `cargo install --locked`; NSIS + WebView2 bootstrapper fetched by the bundler; Azure Trusted Signing via `signtool` + `Azure.CodeSigning.Dlib` with **OIDC federated login** (`azure/login@v2`, no client secret stored); `cloudflare/wrangler-action@v3` for Pages; `gh release create`. PowerShell 5.1 syntax kept in every `.ps1` (the runner's `pwsh` is 7, but the scripts must still run on a 5.1 laptop).

## Global Constraints

- **No secret is ever written to a file that is committed, cached, or uploaded as an artefact.** Secrets enter jobs only as `${{ secrets.* }}` → environment variables or a runner-temp file deleted in `if: always()`. The Trusted Signing profile JSON contains **no secret** (endpoint, account, profile names) and may be written to `%USERPROFILE%\.knowlu\trusted-signing.json` on the runner.
- **The private updater key never exists outside the runner's memory and the GitHub secret store.** Task 4 generates it in a runner-temp directory, sets the secrets from there, and deletes the directory in the same job. Nobody copies it anywhere. If it is ever lost, regenerate: one `pubkey` line and a release (an installed app then needs one manual reinstall — say so in `HANDOFF.md`).
- `cargo test --workspace` at **0 warnings** on every push (the app's `.rsrc merge failure: multiple non-default manifests` linker line is the one accepted message, matched exactly).
- The eight frozen references and the three surface references are never regenerated by anything in CI; CI **reads** `engine/tests/fixtures/` and fails if `git ls-files --eol` shows any fixture other than `attr/-text`.
- **`scripts/release.ps1` is the single release procedure.** CI calls it; a human calls it only with `-DryRun`. A hand-run `cargo tauri build` remains unsupported (CLAUDE.md).
- No workflow uses `pull_request_target`; no third-party action is referenced by a floating major tag except the four named above, each pinned by full commit SHA in the workflow (Task 2 records the SHAs it pins).
- Line endings: workflow files, `.ps1` edits and docs follow `.gitattributes` (`*.ps1` CRLF, everything else LF); `git diff --stat` never shows a whole-file flip.
- Commits: specific `git add`, message via `-F <file>`, trailers `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` and `Claude-Session: https://claude.ai/code/session_014MQESyCz34TjYypAojCJh4`.

- [x] **Step 2: `scripts/ci/toolchain.ps1`** (PowerShell 5.1-safe, runs under pwsh too):

```powershell
# Puts a GNU host toolchain on PATH for the x86_64-pc-windows-gnu Rust target on a GitHub runner.
# -Flavor image   : the runner image's own mingw-w64 (C:\mingw64).
# -Flavor winlibs : the pinned WinLibs POSIX MSVCRT release the dev machine uses, verified by SHA-256.
# Never installs anything outside $env:RUNNER_TEMP. Exit 1 on any failure - a silently missing `as`
# reads as `dlltool ... CreateProcess` failures deep inside a windows-* crate build (CLAUDE.md).
param([ValidateSet("image", "winlibs")][string]$Flavor = "image")
$ErrorActionPreference = "Stop"
if ($Flavor -eq "image") {
  if (-not (Test-Path "C:\mingw64\bin\gcc.exe")) { Write-Output "no C:\mingw64 on this image"; exit 1 }
  Add-Content $env:GITHUB_PATH "C:\mingw64\bin"
  Write-Output "toolchain: image mingw at C:\mingw64"
  exit 0
}
# WinLibs: PIN the exact asset the laptop has (winget BrechtSanders.WinLibs.POSIX.MSVCRT); fill in the
# release's asset URL and SHA-256 in step 3 from `winget show BrechtSanders.WinLibs.POSIX.MSVCRT`.
$url = "<WINLIBS_ASSET_URL>"
$sha = "<WINLIBS_ASSET_SHA256>"
$zip = Join-Path $env:RUNNER_TEMP "winlibs.zip"
Invoke-WebRequest -Uri $url -OutFile $zip
$got = (Get-FileHash $zip -Algorithm SHA256).Hash.ToLowerInvariant()
if ($got -ne $sha.ToLowerInvariant()) { Write-Output "winlibs digest mismatch: $got"; exit 1 }
$dst = Join-Path $env:RUNNER_TEMP "winlibs"
Expand-Archive $zip -DestinationPath $dst -Force
$bin = Get-ChildItem $dst -Recurse -Filter gcc.exe | Select-Object -First 1 | ForEach-Object { $_.DirectoryName }
if (-not $bin) { Write-Output "no gcc.exe in the WinLibs archive"; exit 1 }
Add-Content $env:GITHUB_PATH $bin
Write-Output "toolchain: winlibs at $bin"
exit 0
```

```powershell
# The line-ending contract from .gitattributes, enforced: code and docs LF in the index, PowerShell
# CRLF on checkout, every fixture -text with index bytes equal to working bytes. Exit 1 with the
# offending paths listed. PowerShell 5.1: no &&, no ||.
$ErrorActionPreference = "Stop"
$bad = @()
$rows = git ls-files --eol
foreach ($row in $rows) {
  # format: i/lf    w/lf    attr/text eol=lf    path
  $parts = $row -split "\t"
  $idx = $parts[0].Trim(); $attr = $parts[2].Trim(); $path = $parts[3]
  if ($path -like "engine/tests/fixtures/*") {
    if ($attr -notlike "*-text*") { $bad += "fixture not -text: $path" }
    continue
  }
  if ($path -like "*.ps1") { if ($attr -notlike "*eol=crlf*") { $bad += "ps1 without eol=crlf: $path" }; continue }
  if ($idx -eq "i/crlf" -or $idx -eq "i/mixed") { $bad += "$idx in index: $path" }
}
if ($bad.Count -gt 0) { $bad | ForEach-Object { Write-Output $_ }; exit 1 }
Write-Output ("eol contract holds over " + $rows.Count + " files")
exit 0
```

```powershell
  CertificateProfileName = $env:TS_PROFILE

}

Write-Output "signing profile written to $Path"
exit 0
```
