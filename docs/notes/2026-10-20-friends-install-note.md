# Knowlu: install note for friends who test it

Thank you for testing Knowlu. It is free for you. This page is everything you need, in order.

## 1. What Knowlu is

Knowlu is a Windows desktop app that helps you know what's next.

## 2. This build is unsigned, so Windows will warn you

This test build carries no publisher signature. The first time you run the installer, Windows
SmartScreen shows a blue box saying it protected your PC. That is expected for this test build.

1. Click **More info**.
2. Click **Run anyway**.

## 3. Install

1. Download `Knowlu_<version>_x64-setup.exe` from the latest release:
   https://github.com/quinnhall07/knowlu/releases/latest (under **Assets**). Use this link rather
   than the website's download button, which sits next to the paid prices.
2. Run it and do the SmartScreen clicks above. It installs for your Windows user only.
3. Later versions update themselves. You do not need to download anything again.

## 4. Sign in

Sign in with Google, or ask for a code to be emailed to you and type it in. There is no password.

## 5. The payment step: press no price

Setup reaches a step that shows prices. Do not press a price. Press nothing there.

If you press **Next** and Knowlu answers exactly:

> Finish the payment page in your browser, then come back.

that means wait for Quinn. It does not mean you should pay.

## 6. Tell Quinn who you are, outside the app

Message Quinn (not in Knowlu) with:

- the address you signed in with,
- whether you signed in by Google or by a code, and
- roughly when you did.

## 7. Once Quinn says your access is on

1. Press **Next** again. Setup moves on.
2. Open Settings and read the account row. Tell Quinn what it says. It should read "Free tester
   access through" a date, then "Nothing to pay."

## 8. If something breaks

Tell Quinn what the tray or the message in the app says. The tray menu (right-click the Knowlu icon in the
notification area) has **Copy diagnostics** and **Report an issue**; Report an issue shows you the
whole report before it is sent.

Knowlu keeps logs on your computer under `%LOCALAPPDATA%\knowlu\profiles\<profile id>\logs\`. Do
not send them unless Quinn asks.

## 9. Privacy

Read knowlu.com/privacy. Your school logins never leave your computer: fetch on device, think in
the cloud.
